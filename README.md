One sentence, 200 characters at most, pitching a bizarre startup that sounds
absurd until you realise it would actually sell: tiny funerals for dead
houseplants, sold to grieving owners for $29 a ceremony.

The pitch (188 characters, one sentence):

> We stage tiny funerals for dead houseplants: grieving owners pay $29 for
> the ceremony, eulogy and a replacement plant, because killing a fern still
> hurts and the ritual sells the next one.

Run it:

```sh
node main.ts
```

It prints the pitch and writes it to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
